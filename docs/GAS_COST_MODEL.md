# Mainnet Gas Budget and Cost Model

Closes #378.

## Goal

Quantify worst-case per-submission and per-batch gas costs on mainnet so the
economic model (source rewards, query fees) is based on real numbers instead
of guesses.

## Measuring instruction counts

`contracts/price-oracle/src/gas_benchmarks.rs` prints the CPU instruction and
memory-byte cost of every entry point under the standard mainnet resource
budget (`env.budget().reset_default()` applies the same limits the network
enforces, unlike the unlimited default test budget).

```bash
cd contracts/price-oracle
cargo test bench_ --lib -- --nocapture
```

Each line reports `cpu_instructions` and `mem_bytes` for one entry point
(`initialize`, `submit_price` cold/warm/at-cap, `get_price`,
`add_oracle_source`, etc.).

## Monthly forecast for the default feed

`bench_mainnet_cost_model` (in `gas_benchmarks.rs`) projects the warm-path
`submit_price` instruction count to a monthly total for the default feed
shape — 5 assets, 30 second submission cadence:

```
submissions_per_month = asset_count * (seconds_per_month / cadence_secs)
                       = 5 * (2_592_000 / 30)
                       = 432,000 submissions/month

monthly_cpu_instructions = per_submission_cpu * submissions_per_month
```

Run `cargo test bench_mainnet_cost_model --lib -- --nocapture` to get the
current `per_submission_cpu` figure — it moves as the contract changes, so it
is intentionally computed at test time rather than hard-coded here. To turn
it into a $/month figure, multiply by the mainnet resource fee rate
(`stellar-cli`'s `simulate` output, or the network's current
`ConfigSettingContractComputeV0` price) at the time of the estimate.

## Wiring into the cost dashboard

`docs/COST_OPTIMIZATION.md` (generated by `npm run cost:analyze` from
`config/cost-model.json`) covers Kubernetes infrastructure spend. Contract
gas is a separate, on-chain cost driver — add a "Contract gas" row to that
report's executive summary sourced from this benchmark's monthly instruction
total and the current resource fee rate, refreshed whenever
`gas_benchmarks.rs` changes materially (new entry points, storage layout
changes affecting `submit_price`'s warm path).
