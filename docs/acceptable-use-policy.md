# Acceptable Use Policy

This policy defines the minimum acceptable behavior for users of the Stellar Unified Price Oracle & Aggregator API.

## 1. Lawful and safe use

Consumers must not use the Service to support illegal activity, fraud, harassment, or any activity that violates applicable law or the terms of upstream data providers.

## 2. Security obligations

Consumers must protect their API keys and credentials. Shared keys, hard-coded secrets, or leaked credentials must be rotated immediately. Consumers are expected to comply with the authentication, rate-limiting, and request validation requirements described in the API documentation.

## 3. Operational safeguards

Consumers must avoid:

- sustained traffic spikes that materially degrade service quality for other users;
- repeated retries that create unnecessary load;
- bulk scraping or data extraction that exceeds the published limits;
- attempts to enumerate internal infrastructure, routes, or non-public metadata.

## 4. Abuse response

The operator may temporarily throttle, revoke, or suspend access for abusive, unsafe, or non-compliant usage. Where a violation is material, the operator may require remediation before restoring access.

## 5. Data handling

Users are responsible for the lawful use and retention of any data they obtain via the Service. Users may not redistribute primary data in a way that violates source-provider licensing or the published Service terms.

## 6. Enforcement

This policy is enforced through API key controls, rate limiting, and operational monitoring. Continued access depends on compliance with the service terms, API policies, and applicable law.
