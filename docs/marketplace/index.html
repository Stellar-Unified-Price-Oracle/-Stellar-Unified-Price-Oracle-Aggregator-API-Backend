Sandbox environment

The sandbox is read-only by default and is intentionally isolated from production resources, keys, and billing data.

curl https://sandbox.example/api/v1/sandbox/info
curl -X POST https://sandbox.example/api/v1/sandbox/reset \
  -H 'x-sandbox-reset-token: <local-token>'

Resetting the sandbox invalidates the in-memory cache and repopulates the deterministic fixtures used by the read-only endpoints.
